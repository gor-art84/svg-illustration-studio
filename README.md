# Конструктор SVG-иллюстраций

Веб-сервис для сборки иллюстраций из объектов библиотеки Figma. В каталоге 10 объектов. Каждый доступен в детализациях S и L, в цветном и фоновом вариантах. Готовая композиция скачивается как SVG с отдельными группами объектов и редактируемыми контурами.

## Запуск

Склонируйте репозиторий и откройте `index.html` в современном браузере. Проект работает локально, без установки зависимостей, сборки и API-ключей.

```sh
git clone https://github.com/gor-art84/svg-illustration-studio.git
cd svg-illustration-studio
```

Для запуска через локальный HTTP-сервер используйте Python 3.

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Откройте [конструктор на localhost](http://127.0.0.1:8000).

## Короткая демонстрация

[Запись работы конструктора, 14 секунд](demo/demo.webm).

1. **Сборка по идее.** Введите «Вечер за учёбой». Подбор по тегам предложит лампу, книгу и ручку.
2. **Сборка по названиям.** Выберите другой режим и введите «Телефон, пазлы, монета». Объекты будут размещены в указанном порядке.
3. **Редактирование.** Перетащите объект на холсте. В панели слоёв можно задать координаты и угол, дублировать объект, удалить его или изменить порядок наложения.
4. **Палитра и экспорт.** Выберите встроенную схему или загрузите [JSON-шаблон с восемью цветами](palette-example.json). Нажмите **«Скачать SVG»**. Чтобы проверить редактируемость, импортируйте файл в Figma и раскройте группу объекта.

## Как устроена работа с SVG

| Файл | Назначение |
| --- | --- |
| [`library.js`](library.js) | Каталог из 40 векторных вариантов. У каждого объекта есть стабильный ключ, русское название и SVG-группы по детализации и роли. |
| [`extract_library.py`](extract_library.py) | Извлекает именованные группы из двух SVG-экспортов секций Figma. Сохраняет геометрию и атрибуты контуров, удаляет исходные идентификаторы слоёв, чтобы повторные экземпляры не конфликтовали. |
| [`assembly.js`](assembly.js) | Нормализует русский текст. По заголовку подбирает до трёх объектов по словарю тегов. По списку ищет точные названия и синонимы, сохраняя порядок ввода. |
| [`editor.js`](editor.js) | Хранит состояние сцены, собирает SVG для холста и скачивания, управляет позициями, слоями, форматами и палитрой. |

Объект сцены хранит ключ библиотечного элемента, роль, уникальный идентификатор, координаты центра и угол. Порядок в массиве задаёт порядок рисования. SVG-группа извлекается из каталога и клонируется для каждого экземпляра. Положение, поворот и равномерное масштабирование задаются через `transform` на внешней группе.

При смене формата автоматически собранная сцена раскладывается заново. После ручных правок редактор вписывает композицию целиком, сохраняя взаимное расположение объектов и их повороты. Детализация S/L выбирает вариант вектора для каждого объекта и работает независимо от формата холста.

Палитра сопоставляет восемь исходных цветов с новыми значениями. Редактор заменяет цвета в атрибутах `fill`, `stroke` и `stop-color`, затем сериализует композицию с размерами холста, `viewBox` и именованными группами. Рамки выделения принадлежат интерфейсу редактора. Их нет в скачанном SVG.

Для обновления каталога экспортируйте секции **«Размер S»** и **«Размер L»** из Figma в SVG с включённым **Include “id” attribute**, затем выполните:

```sh
python3 extract_library.py path/to/size-s.svg path/to/size-l.svg library.js
```

Полные выгрузки секций Figma не нужны для запуска. Каталог уже содержит извлечённые векторные объекты из материалов задания.

## Проверка результата

Проверены оба сценария автосборки, перетаскивание мышью, поворот, дублирование, порядок слоёв, три формата холста и загрузка JSON-палитры. При импорте тестовых SVG в настольную Figma проверены размеры фреймов, новые цвета и возможность выбрать и перекрасить отдельный векторный контур.
